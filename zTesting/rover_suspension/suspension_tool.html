Model, conventions & verification
  • True parallelogram: wall and wheel plate stay vertical; both bars share angle θ above horizontal. Active height z = L·sinθ (z = 0 with bars level); θ > 0 = wheel raised = compression.
  • x1, x2 are along-the-bar distances from the wall pivots. With d = x2 − x1: spring length s(θ) = √(d² + h² − 2·h·d·sinθ).
  • Motion ratio ds/dz = −h·d / (L·s) (the cosθ cancels). Spring force by virtual work: F = N·L·s / (h·d), with wheel load N = m·g/4 × G. d > 0 loads the spring in compression, d < 0 in tension.
  • Pivot loads come from the full 9-equation rigid-body statics of the two bars + plate (massless links, pin joints, vertical wheel load at horizontal offset w from the plate). The wheel offset changes pivot loads only — never the spring force.
  • Bar axial forces and the bending moment at each spring pin (reported in the pivot-load table) are taken from the outboard bar segment; axial + = tension.
  • Verified against an independent Python implementation: 2000 randomized configurations, spring force from the statics solve vs. virtual work agree to <1e-13 relative; this page re-runs a fixed regression case + a sweep self-check at load (see footer badge).
